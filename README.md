# 🌿 GreenShop (BetterPlanet)

**GreenShop** is a modern e-commerce web application for buying house plants and home accessories. The project provides a seamless shopping experience with product filtering, category browsing, and cart management.

---

## Key Features

- **Product Catalog:** Browse a wide range of plants with clear pricing and high-quality images.
- **Filtering & Sorting:** Easily filter items by category (_Terrariums_, _House Plants_, etc.), size (_Small_, _Medium_, _Large_), and sort by price or popularity.
- **Shopping Cart:** Full cart functionality allowing users to add, remove, and update item quantities.
- **User Authentication:** Login and registration interface for customer accounts.
- **Smooth Navigation:** Multi-page experience powered by React Router.
- **Newsletter Subscription:** Integrated subscription form for special offers and updates.

---

## Tech Stack

- **Frontend:** React
- **Build Tool:** Vite
- **Styling:** CSS Modules
- **Routing:** React Router

## 💻 Getting Started Locally

To run this project on your local machine, follow these steps:

1. **Clone the repository:**

   ```bash
   git clone https://github.com/RVasyliuk-2003/BetterPlanet.git
   ```

2. **Navigate to the project folder:**

   ```bash
   cd BetterPlanet
   ```

3. **Install dependencies:**

   ```bash
   npm install
   ```

4. **Run the project:**
   ```bash
   npm run dev
   ```
